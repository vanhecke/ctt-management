Sub-playbook of `CTT - Hygiene - Notify Owner`, one question round per run; the parent's task loops it until the answer closes the issue (at most 10 rounds). It runs in the parent's context (CTT.Triage) and writes its result to CTT.FixCheck (`close`, `reason`, `note`). The parent closes the issue.

1. **Did you fix it?** is asked by Generated link (no timeout); in parallel `CTTHygieneAskLinks` gets its links and `CTTHygieneSendDM` sends the DM with the buttons **Mark as Fixed**, **Mark as False Positive** and **View Issue** (`notify.buttons`; otherwise links in the text). Without a DM (DMs off, not on the allowlist, no Slack ID, daily limit) only the DM is skipped.
2. **Mark as Fixed** runs `CTTHygieneFixCheck confirm=true resolve=false`: a verified fix (or a guideline without a check) ends the round with `close`. Otherwise the round writes the check's note to `CTT.Reask.note` and ends; the next round's DM starts with it ("You said this is fixed, but the check still sees it: …").
3. **Mark as False Positive** runs `CTTHygieneFixCheck false_positive=true resolve=false` (a post in the CTT channel) and ends with `close` (False Positive).
