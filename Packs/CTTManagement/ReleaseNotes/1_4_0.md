#### Playbooks

##### CTT - Hygiene - Notify Owner

After the DM the playbook now waits for the owner: the question "Did you fix it?" is asked by Generated link, and the DM carries the answers as Slack buttons Mark as Fixed / Mark as False Positive / View Issue (`notify.buttons`). Mark as Fixed runs the fix check: a verified fix, or a guideline without a check, closes the issue; otherwise a second round asks once more and says what is still wrong. Mark as False Positive closes the issue as False Positive and tells the CTT channel. A parallel watch checks the fix every hour and closes the issue once the check sees it fixed. The issue is always closed by the last task of a branch, with a close note. When a DM can't go out (daily limit, `notify.mode`, allowlist, no Slack ID) only the DM is skipped; the question, In Progress and the watch run as usual. A duplicate (the same endpoint, user or object already has an open issue, or was marked a false positive in the last `notify.false_positive_days` days) is closed as Duplicate Issue before anyone is assigned or DMed: the daily rules raised the same finding again every day.

##### New: CTT - Hygiene - Fix Check

Runs `CTTHygieneFixCheck` every hour (job of the same name).

##### New: CTT - Hygiene - Reminders

Runs `CTTHygieneFixCheck remind=true` every day at 10:00 SGT (job of the same name).

#### Correlation Rules

##### CTT - Hygiene - Endpoint outside owner's lab range

A lab octet now covers `172.16.<octet>.0/24` as well as `10.<octet>.0.0/16` (CTT-LAB-01). The endpoint field is `lab_ip` (was `ip10`).

#### Scripts

##### New: CTTHygieneFixCheck

Checks open CTT hygiene issues from the correlation rules and resolves the fixed ones with a close note saying why: GEN-01 registry entries, TAG-01/TAG-04 renamed or deleted objects (TAG-01: or a playbook with the owner's tag in its Tags field), TAG-02 policy scopes, OOTB-01 re-attached built-in playbooks and scripts, LAB-01 endpoint ranges. Also handles the owner's Mark as Fixed and Mark as False Positive answers and sends the daily digests. Closes hygiene cases once all their issues are resolved (a resolved issue left its case open).

##### New: CTTHygieneAskLinks

Returns the newest answer links of the Notify Owner question for the DM.

##### CTTHygieneSendDM

New arguments `fixed_url`, `not_violation_url`, `buttons` and `note`.

##### CTTHygieneTriage

New outputs `CTT.Triage.buttons` (`notify.buttons` in `CTT - Config`) and `CTT.Triage.duplicate_of` / `duplicate_note` / `duplicate_reason`. The LAB-01 fix advice names both lab ranges; the TAG-01 advice for a playbook offers the Tags field.

##### CTTInventoryCheck

CTT-TAG-01: a playbook with a registered tag in its Tags field needs no name prefix; that tag names its owner.

##### CTTCaseHousekeeping

Lab addresses in `172.16.<octet>.0/24` count for the owner's lab octet, like `10.<octet>.0.0/16`.

##### CTTRegistryLookup

Accepts `172.16.<octet>.x` addresses and shows both lab ranges of an owner.

##### CTTEnsureJobs

Jobs now get `category: job`, `parent` (their own id), `endingType` and an owner, as the web UI sets them. Without these the scheduler dropped every run silently, so no CTT job had run its playbook. New argument `owner` (default: the job's owner, else the user running the script). Existing jobs are repaired on the next run; a job disabled on the tenant stays disabled.

##### CTTTenantStatus

The HYGIENE section shows closes by way, median time to fix per guideline, top fixers and the oldest open issue.

#### Integrations

##### CTT Slack Webhook

New action `msg_person_health_issue`: a DM with the buttons Mark as Fixed (`fixed_url`), Mark as False Positive (`not_violation_url`) and View Issue (`issue_url`). Every call now sends the three button inputs (`-` when unused), as the workflow's webhook declares them.

#### Actions

##### New: CTTHygieneConfirmFixAction

The CTT Assistant records a fix the user reports and runs the fix check (with the user's approval).

#### Lists

##### CTT - Config

New `notify.buttons` (default `true`) and `notify.false_positive_days` (default 30).

##### CTT - Jobs

Adds the `CTT - Hygiene - Fix Check` and `CTT - Hygiene - Reminders` jobs, and the job fields the scheduler needs to run them. The job playbooks now close their run in their last task. Run `!CTTEnsureJobs remove_obsolete=true` after upgrading.
