#### Playbooks

##### CTT - Hygiene - Notify Owner

After the DM the playbook now waits for the owner: the question "Did you fix it?" is asked by Generated link, and the DM carries the answer links (Slack buttons Mark as Fixed / Mark as False Positive / View Issue with `notify.buttons`). Mark as Fixed runs the fix check: a verified fix, or a guideline without a check, is resolved with a close note; otherwise the question is asked again and the next DM says what is still wrong. Mark as False Positive resolves the issue as False Positive and tells the CTT channel.

##### New: CTT - Hygiene - Fix Check

Runs `CTTHygieneFixCheck` every hour (job of the same name).

##### New: CTT - Hygiene - Reminders

Runs `CTTHygieneFixCheck remind=true` every day at 10:00 SGT (job of the same name).

#### Scripts

##### New: CTTHygieneFixCheck

Checks open CTT hygiene issues from the correlation rules and resolves the fixed ones with a close note saying why: GEN-01 registry entries, TAG-01/TAG-04 renamed or deleted objects, TAG-02 policy scopes, OOTB-01 re-attached built-in playbooks and scripts, LAB-01 endpoint ranges. Also handles the owner's Mark as Fixed and Mark as False Positive answers and sends the daily digests. Closes hygiene cases once all their issues are resolved (a resolved issue left its case open).

##### New: CTTHygieneAskLinks

Returns the newest answer links of the Notify Owner question for the DM.

##### CTTHygieneSendDM

New arguments `fixed_url`, `not_violation_url`, `buttons` and `note`.

##### CTTHygieneTriage

New output `CTT.Triage.buttons` (`notify.buttons` in `CTT - Config`).

##### CTTTenantStatus

The HYGIENE section shows closes by way, median time to fix per guideline, top fixers and the oldest open issue.

#### Integrations

##### CTT Slack Webhook

New action `msg_person_health_issue`: a DM with the buttons Mark as Fixed (`fixed_url`), Mark as False Positive (`not_violation_url`) and View Issue (`issue_url`). Every call now sends the three button inputs (`-` when unused), as the workflow's webhook declares them.

#### Agentix Actions

##### New: CTTHygieneConfirmFixAction

The CTT Assistant records a fix the user reports and runs the fix check (with the user's approval).
