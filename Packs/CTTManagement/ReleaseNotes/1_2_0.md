## CTT Management

- The `CTT - Hygiene - Notify Owner` automation rule is enabled on install (`is_auto_enabled`). The Notify Dispatcher job, its playbook and `CTTHygieneDispatch` are removed; run `!CTTEnsureJobs remove_obsolete=true` after upgrading.
- New correlation rule `CTT - Hygiene - Policy rule not scoped by your tag` (CTT-TAG-02). The built-in content rule (CTT-OOTB-01/02) applies to CTT admins too. The lab range rule (CTT-LAB-01) finds owners through the creator of an endpoint's installer and the last editor of its policy rule. Issue texts use readable object kinds (Correlation rule, Policy rule, Agent installer).
- New `CTTOwnerIndex` script and `ctt_object_owners` lookup, updated every hour by the `CTT - Registry Sync` job.
- `CTTHygieneSweep` is now `CTTInventoryCheck` (`CTT - Hygiene - Inventory Check` job): only checks the correlation rules can't make, with owners from the audit log, skipping objects already in an open rule issue. Stale cases are no longer raised as hygiene issues.
- New `CTTCaseHousekeeping` script and `CTT - Case Housekeeping` job: assigns Security cases unassigned for a day, reminds owners to close quiet cases, and resolves cases open for 7 days as Security Testing (starred cases are skipped). Ships in dry-run mode (`cases.dry_run`).
- `CTT - Tenant Status`: the channel topic shows tenant activity only (open and new cases, connected endpoints, ingestion, active integrations). The canvas has an Automation section with top playbooks and AI agent plans. Open-case counts now count open cases, not all cases.
