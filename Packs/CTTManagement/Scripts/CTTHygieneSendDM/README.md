Sends the CTT hygiene DM through the `CTT Slack Webhook` integration (`msg_person`). The CTT Slack workflow shows the DM in a code block, so the script lays it out in ASCII: a header box with the guideline ID, the message from `CTTHygieneMessagePrompt` (or the template from `CTTHygieneTriage`) wrapped to 46 characters, and a footer with the issue number and link. The link is also sent as the `url` key when the integration instance enables it. DMs are counted per owner per day in the `CTT - Notify State` list.

With `closed=true` it sends the thank-you DM instead (header `CTT HYGIENE · CLOSED`, a thank-you, the close note under WHY, the issue link). The Notify Owner playbook sends it before closing an issue after the owner's answer or the hourly check. A false positive gets its own wording. Thank-you DMs don't count toward `notify.max_dms_per_owner_per_day`.
