Starts the `CTT - Hygiene - Notify Owner` playbook on new, unassigned CTT hygiene issues. Run every 15 minutes by the `CTT - Hygiene - Notify Dispatcher` job: pack uploads to XSIAM 8.15 do not install automation rules (triggers), so this job does what the trigger would. Issues that already run a playbook are skipped, and dispatched issue IDs are kept in the `CTT - Dispatch State` list.
